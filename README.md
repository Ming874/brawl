# 🐶🐱 毛毛大亂鬥 Fluffy Brawl

憨憨毛茸茸動物的多人連線派對遊戲：可以一起**釣魚**、也可以在海上擂台**大亂鬥**（不血腥，被打只會冒星星、頭暈、掉進海裡變落湯雞）。

## 遊戲特色

- **兩隻憨憨角色**：橘白配色的柴犬「橘寶」、灰白配色的虎斑貓「灰灰」，毛茸茸的毛髮效果、Q 彈晃動的大頭、會亂飄的呆萌眼睛。
- **裝扮**：10 種帽子（毛線帽、派對帽、草帽、皇冠、漁夫帽、牛仔帽、小鴨、廚師帽、花圈）＋ 5 種圍巾/領巾/領結，每種都有 12 種顏色。
- **湖畔釣魚**：拋竿蓄力 → 等浮標下沉 → 拉竿 → 收線小遊戲（張力太高線會斷！），17 種魚與雜物，1～5 星稀有度，拋越遠越容易釣到稀有魚。有**釣魚圖鑑**會記錄每種魚的最大紀錄。
- **擂台大亂鬥**：出拳、飛撲、抓起來、丟下海！連續被打會頭暈，暈倒時可以被抓起來丟出去；最後留在擂台上的人贏得回合，先拿 3 勝的是冠軍。
- **多人連線**：建立房間（5 碼房間代碼）、輸入代碼加入；房主可以切換「釣魚／大亂鬥」模式、加入電腦玩家。
- **好友系統**：每個玩家都有自己的**玩家代碼**（例如 `AB12-CD34`），輸入代碼送出好友邀請，對方接受後就是好友；可以看到好友在線狀態，**邀請好友進入你的房間**，或直接加入好友所在的房間。
- 房間內聊天、表情動作（揮手、跳舞、坐下）。

## 怎麼開始玩

### 1. 安裝 Node.js（只需一次）
到 <https://nodejs.org> 下載安裝 LTS 版本。

### 2. 啟動伺服器
- **Windows**：直接雙擊 `start.bat`（第一次會自動安裝套件），會自動打開瀏覽器。
- 或用指令：
  ```bash
  npm install
  npm start
  ```
然後用瀏覽器（建議 Chrome / Edge）打開 <http://localhost:3000>。

### 3. 跟朋友一起玩
- **同一個 Wi-Fi / 區域網路**：伺服器視窗會顯示「區網朋友：http://192.168.x.x:3000」，把這個網址傳給朋友打開即可（第一次可能要允許 Windows 防火牆）。
- **透過網路（不同地方）**，二選一：
  - **快速分享**：安裝 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) 後執行
    `cloudflared tunnel --url http://localhost:3000`，把它給的 `https://xxxx.trycloudflare.com` 網址傳給朋友。
  - **放到雲端**：專案內附 `render.yaml`，可以在 [Render](https://render.com) 用「New → Blueprint」連結這個 GitHub 專案一鍵部署（免費方案重新部署後玩家資料會重置）。

## 操作方式

| 按鍵 | 動作 |
| --- | --- |
| `W A S D` | 移動 |
| `Shift` | 奔跑 |
| `空白鍵` | 跳躍／游泳時往上爬 |
| 滑鼠 | 轉動鏡頭，滾輪調整遠近 |
| `左鍵` | 出拳（左右交替） |
| `右鍵`（按住） | 抓住對方；抓住時按 `左鍵` 丟出去 |
| `F` | 飛撲 |
| `E` | 拿出／收起釣竿（湖畔釣魚模式） |
| 釣竿時 `左鍵` | 按住蓄力、放開拋竿；浮標下沉時點一下拉竿；收線時按住，張力太高要放開 |
| `1` `2` `3` | 揮手、跳舞、坐下 |
| `Enter` | 聊天 |
| `Tab`／`Esc` | 房間選單（邀請好友、切換模式、加電腦玩家、離開房間） |
| `B` | 釣魚圖鑑 |

被抓住時狂按 `空白鍵` 可以掙脫！

## 技術說明

- 前端：[three.js](https://threejs.org)（WebGL），所有角色、帽子、魚、地圖都用程式即時建模，不需要任何圖片或模型檔；音效用 WebAudio 即時合成。
- 毛髮：殼層（shell）毛髮著色器 + 絨布光澤材質。
- 後端：Node.js + [ws](https://github.com/websockets/ws)，負責帳號（玩家代碼）、好友、房間、邀請、狀態轉送、擂台回合。
- 玩家資料存在 `data/players.json`（自動建立）。
- 畫質可以在「設定」調整（高／中／低），筆電建議用「中」或「低」。
